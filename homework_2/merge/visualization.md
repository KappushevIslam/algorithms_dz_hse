Задача. Слить два отсортированных односвязных списка в один.

Вход:
list1 [1, 2, 4]
list2 [1, 3, 4]

Шаг 1. Текущие 1 и 1. Условие меньше либо равно истинно. Взят узел list1.
Состояние: результат [1] list1 [2, 4] list2 [1, 3, 4]

Шаг 2. Текущие 2 и 1. Взят узел list2.
Состояние: результат [1, 1] list1 [2, 4] list2 [3, 4]

Шаг 3. Текущие 2 и 3. Взят узел list1.
Состояние: результат [1, 1, 2] list1 [4] list2 [3, 4]

Шаг 4. Текущие 4 и 3. Взят узел list2.
Состояние: результат [1, 1, 2, 3] list1 [4] list2 [4]

Шаг 5. Текущие 4 и 4. Условие меньше либо равно истинно. Взят узел list1.
Состояние: результат [1, 1, 2, 3, 4] list1 [] list2 [4]

Шаг 6. Первый список пуст. Остаток второго дописан целиком.

Итог. Ответ [1, 1, 2, 3, 4, 4]. Новые узлы не создавались.
