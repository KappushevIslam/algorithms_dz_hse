Задача. Реализовать стек и очередь на основе связных списков.

Вход:
push 1, push 2, push 3, pop для стека
enqueue 1, enqueue 2, enqueue 3, dequeue для очереди

Шаг 1. Push 1. Вершина указывает на узел 1.
Состояние стека: 1

Шаг 2. Push 2. Новый узел ссылается на узел 1.
Состояние стека: 2 -> 1

Шаг 3. Push 3. Новый узел ссылается на узел 2.
Состояние стека: 3 -> 2 -> 1

Шаг 4. Pop. Возвращено 3. Вершина сдвинута на узел 2.
Состояние стека: 2 -> 1

Шаг 5. Enqueue 1. Голова и хвост указывают на узел 1.
Состояние очереди: 1

Шаг 6. Enqueue 2. Узел 1 ссылается на узел 2. Хвост сдвинут на узел 2.
Состояние очереди: 1 -> 2

Шаг 7. Enqueue 3. Узел 2 ссылается на узел 3. Хвост сдвинут на узел 3.
Состояние очереди: 1 -> 2 -> 3

Шаг 8. Dequeue. Возвращен 1. Голова сдвинута на узел 2.
Состояние очереди: 2 -> 3

Итог. Стек снял 3 последним добавленным. Очередь сняла 1 первым
добавленным. Все операции изменили фиксированное число ссылок.
