Задача. Проверить достижимость порядка pop на стеке для порядка push.

Вход:
pushed [1, 2, 3, 4, 5]
popped [1, 3, 5, 4, 2]

Шаг 1. Push 1. Стек [1]. Верх равен popped 0. Pop. Pos 1.
Состояние: стек [] pos 1

Шаг 2. Push 2. Стек [2]. Верх 2 отличается от popped 1 равного 3. Пауза.
Состояние: стек [2] pos 1

Шаг 3. Push 3. Стек [2, 3]. Верх равен popped 1. Pop. Pos 2.
Состояние: стек [2] pos 2

Шаг 4. Push 4. Стек [2, 4]. Верх 4 отличается от popped 2 равного 5. Пауза.
Состояние: стек [2, 4] pos 2

Шаг 5. Push 5. Стек [2, 4, 5]. Верх равен popped 2. Pop. Pos 3.
Состояние: стек [2, 4] pos 3

Шаг 6. Верх 4 равен popped 3. Pop. Pos 4. Верх 2 равен popped 4. Pop. Pos 5.
Состояние: стек [] pos 5

Итог. Pos 5 равно длине popped. Ответ True.

Второй пример. pushed [1, 2, 3] popped [3, 1, 2].
Шаг 1. Push 1 2 3 без снятий. Стек [1, 2, 3].
Шаг 2. Верх 3 равен popped 0. Pop. Pos 1. Стек [1, 2].
Шаг 3. Верх 2 отличается от popped 1 равного 1. Снятий больше нет.
Итог. Pos 1 меньше длины popped. Ответ False.
