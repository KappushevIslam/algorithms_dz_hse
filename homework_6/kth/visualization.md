Задача. Поиск 2-го по величине элемента методом quickselect с трехсторонним разделением.

Вход:
[3, 2, 1, 5, 6, 4], k 2

Шаг 1. Отрезок 0 5. Пивот из середины индекса 2, значение 1.
Состояние: меньше [], равно [1], больше [2, 5, 6, 4, 3].
Состояние: полный массив [1, 2, 5, 6, 4, 3], отрезок 1 5.
Пояснение: справа 5 элементов, k 2 находится в правой части. Группа равных из одного элемента отброшена. Отрезок сужен до 1 5.

Шаг 2. Отрезок 1 5. Пивот из середины индекса 3, значение 6.
Состояние: меньше [2, 5, 4, 3], равно [6], больше [].
Состояние: полный массив [1, 2, 5, 4, 3, 6], отрезок 1 4.
Пояснение: правая часть пуста, группа равных содержит максимум. Счетчик обновлен: 2 минус 1 равно 1. Группа равных отброшена. Отрезок сужен до 1 4.

Шаг 3. Отрезок 1 4. Пивот из середины индекса 2, значение 5.
Состояние: меньше [2, 4, 3], равно [5], больше [].
Состояние: полный массив [1, 2, 4, 3, 5, 6], отрезок 1 4.
Пояснение: k 1 попадает в группу равных. Пивот фиксирует ответ.

Итог. Ответ 5. Алгоритм выполнил 3 разделения и 2 сужения отрезка.
