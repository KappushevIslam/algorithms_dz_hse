Задача. Итеративная сортировка слиянием снизу вверх и быстрая сортировка с явным стеком.

Вход:
[4, 1, 3, 2, 6, 5]

Шаг 1. Проход слиянием при ширине 1. Пары [4] [1], [3] [2], [6] [5] сливаются в [1, 4], [2, 3], [5, 6].
Состояние:
Массив: [1, 4, 2, 3, 5, 6]

Шаг 2. Проход слиянием при ширине 2. Пара [1, 4] [2, 3] сливается в [1, 2, 3, 4]. Хвост [5, 6] копируется.
Состояние:
Массив: [1, 2, 3, 4, 5, 6]

Шаг 3. Проход слиянием при ширине 4. Пара [1, 2, 3, 4] [5, 6] сливается в [1, 2, 3, 4, 5, 6].
Состояние:
Массив: [1, 2, 3, 4, 5, 6]

Шаг 4. Быстрая сортировка. Стек [(0, 5)]. Извлечена пара (0, 5). Опорный 5. Разбиение дает индекс 4. Массив [4, 1, 3, 2, 5, 6]. Стек [(0, 3), (5, 5)].
Состояние:
Массив: [4, 1, 3, 2, 5, 6]

Шаг 5. Извлечена пара (5, 5). Отрезок длины 1 пропускается. Стек [(0, 3)].
Состояние:
Массив: [4, 1, 3, 2, 5, 6]

Шаг 6. Извлечена пара (0, 3). Опорный 2. Разбиение дает индекс 1. Массив [1, 2, 3, 4, 5, 6]. Стек [(0, 0), (2, 3)].
Состояние:
Массив: [1, 2, 3, 4, 5, 6]

Шаг 7. Извлечена пара (2, 3). Опорный 4. Разбиение дает индекс 3. Массив [1, 2, 3, 4, 5, 6]. Стек [(0, 0), (2, 2), (4, 3)].
Состояние:
Массив: [1, 2, 3, 4, 5, 6]

Шаг 8. Пары (4, 3), (2, 2), (0, 0) извлекаются по очереди. Отрезки длины 0 или 1 пропускаются. Стек пуст.
Состояние:
Массив: [1, 2, 3, 4, 5, 6]

Итог. Ответ [1, 2, 3, 4, 5, 6]. Слияние выполнило 3 прохода.
