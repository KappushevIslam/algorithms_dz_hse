Задача. Сравнение сортировки слиянием и быстрой сортировки с замером времени.

Вход:
[5, 2, 4, 1, 3]

Шаг 1. Слияние делит [5, 2, 4, 1, 3] на [5, 2] и [4, 1, 3]. Середина проходит по индексу 2.
Состояние:
лево [5, 2]
право [4, 1, 3]

Шаг 2. Левая половина [5, 2] делится на [5] и [2]. Отрезки длины один готовы к слиянию.
Состояние:
[5] плюс [2] дает [2, 5]

Шаг 3. Правая половина [4, 1, 3] делится на [4] и [1, 3]. Пара [1, 3] делится на [1] и [3].
Состояние:
[1] плюс [3] дает [1, 3]

Шаг 4. Слияние [4] и [1, 3] дает [1, 3, 4]. Сравнение идет по головам отрезков.
Состояние:
[4] плюс [1, 3] дает [1, 3, 4]

Шаг 5. Слияние [2, 5] и [1, 3, 4] дает [1, 2, 3, 4, 5]. Указатели движутся по обеим половинам.
Состояние:
[2, 5] плюс [1, 3, 4] дает [1, 2, 3, 4, 5]

Шаг 6. Быстрая сортировка берет опорный 3 из конца [5, 2, 4, 1, 3]. Разбиение Ломуто ставит 3 на позицию 2.
Состояние:
[2, 1, 3, 5, 4]
лево [2, 1], право [5, 4]

Шаг 7. Правая часть [5, 4] берет опорный 4. Разбиение ставит 4 на позицию 3.
Состояние:
[2, 1, 3, 4, 5]
лево [2, 1], право [5]

Шаг 8. Левая часть [2, 1] берет опорный 1. Разбиение ставит 1 на позицию 0.
Состояние:
[1, 2, 3, 4, 5]

Итог. На отсортированном входе длины 1000 быстрая сортировка выполняет квадратичное число сравнений из-за выбора последнего элемента опорным, слияние держит логарифмическую глубину деления, замер показывает разрыв в разы в пользу слияния.
