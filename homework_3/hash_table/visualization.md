Задача. Реализовать хеш-таблицу с вставкой, поиском и удалением.

Вход:
емкость 4, вставка eat, tea, ключа 10

Шаг 1. Insert eat. Хеш строки eat по модулю 4 дает корзину 0. Корзина 0
пуста. Запись добавлена в конец цепочки.
Состояние корзин:
0: [[eat, 1]]
1: []
2: []
3: []

Шаг 2. Insert tea. Хеш строки tea по модулю 4 дает корзину 0. Корзина 0
занята записью eat. Коллизия разрешена цепочкой. Запись добавлена в конец.
Состояние корзин:
0: [[eat, 1], [tea, 2]]
1: []
2: []
3: []

Шаг 3. Insert 10. Хеш 10 по модулю 4 дает корзину 2. Корзина 2 пуста.
Размер стал 3. Порог емкости 4 равен 3. Условие расширения требует
строгого превышения. Расширения нет.
Состояние корзин:
0: [[eat, 1], [tea, 2]]
1: []
2: [[10, 3]]
3: []

Шаг 4. Get tea. Индекс корзины 0. Перебор цепочки находит tea второй
записью. Возвращено 2.

Шаг 5. Remove eat. Индекс корзины 0. Первая запись цепочки удалена.
Размер стал 2.
Состояние корзин:
0: [[tea, 2]]
1: []
2: [[10, 3]]
3: []

Итог. Поиск вернул 2. После удаления размер 2. Хранение использует только
списки на всех уровнях.
