Задача. Найти индексы двух элементов массива с суммой k.

Вход:
arr [1, 3, 4, 10]
k 7

Шаг 1. i 0 value 1. Дополнение 6. Словарь пуст. Запись 1 с индексом 0.
Состояние: seen {1: 0}

Шаг 2. i 1 value 3. Дополнение 4. Значения 4 в словаре нет. Запись 3
с индексом 1.
Состояние: seen {1: 0, 3: 1}

Шаг 3. i 2 value 4. Дополнение 3. Значение 3 найдено с индексом 1.
Индексы упорядочены по возрастанию.

Итог. Ответ (1, 2). Проверка 3 плюс 4 равно 7.

Второй пример. arr [5, 5, 1, 4] k 10.
Шаг 1. i 0 value 5. Дополнение 5. Словарь пуст. Запись 5 с индексом 0.
Шаг 2. i 1 value 5. Дополнение 5. Значение 5 найдено с индексом 0.
Итог. Ответ (0, 1). Проверка 5 плюс 5 равно 10.
