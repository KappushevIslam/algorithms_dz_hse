Задача. Все перестановки массива чисел.

Вход:
[1, 2]

Шаг 1. Вход backtrack([], [1, 2]). Глубина 0. Перебор стартует с двух ветвей.
Дерево вызовов:
  backtrack([], [1, 2])

Шаг 2. Выбор 1. Вход backtrack([1], [2]). Глубина 1. Отступ два пробела.
Дерево вызовов:
  backtrack([], [1, 2])
    backtrack([1], [2])

Шаг 3. Выбор 2. Вход backtrack([1, 2], []). Глубина 2. Остаток пуст. Фиксация [1, 2].
Возврат backtrack([1, 2], []) = None. Отмена 2 и 1.

Шаг 4. Выбор 2. Вход backtrack([2], [1]). Глубина 1. Вторая ветвь верхнего уровня.
Дерево вызовов:
  backtrack([], [1, 2])
    backtrack([2], [1])

Шаг 5. Выбор 1. Вход backtrack([2, 1], []). Глубина 2. Фиксация [2, 1].

Итог. Ответ [[1, 2], [2, 1]]. Глубина равна длине входа. Число листьев равно факториалу.
