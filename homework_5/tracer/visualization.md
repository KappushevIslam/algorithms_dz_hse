Задача. Декоратор tracer показывает стек вызовов рекурсивной функции.

Вход:
fact(3)

Шаг 1. Вход fact(3). Глубина 0. Печать без отступа.
Состояние:
call fact(3)

Шаг 2. Вход fact(2). Глубина 1. Печать с отступом два пробела.
Состояние:
call fact(3)
  call fact(2)

Шаг 3. Вход fact(1). Глубина 2. Печать с отступом четыре пробела.
Состояние:
call fact(3)
  call fact(2)
    call fact(1)

Шаг 4. База n 1. Возврат 1. Отступ четыре пробела.
Состояние:
    call fact(1)
    return fact(1) = 1

Шаг 5. Возврат fact(2) 2. Отступ два пробела.
Состояние:
  call fact(2)
  return fact(2) = 2

Шаг 6. Возврат fact(3) 6. Отступ пустой.
Состояние:
call fact(3)
return fact(3) = 6

Итог. Ответ 6. Журнал содержит 6 строк: 3 входа и 3 возврата.
