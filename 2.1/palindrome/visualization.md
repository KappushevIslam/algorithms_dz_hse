Задача. Проверить целое положительное число на палиндром без строк.

Вход:
121

Шаг 1. Проверка окончания. Остаток 1. Отсечение не сработало.
Состояние: x 121 rev 0

Шаг 2. Перенос цифры 1. Целочисленное деление убрало младший разряд.
Состояние: x 12 rev 1

Шаг 3. Перенос цифры 2. Правая половина обогнала левую часть.
Состояние: x 1 rev 12

Шаг 4. Цикл остановлен. Средняя цифра 2 находится в rev. Деление rev на 10
убирает среднюю цифру. Сравнение 1 равно 1 дало истину.

Итог. Ответ True.

Второй пример. Вход 31.

Шаг 1. Состояние: x 31 rev 0. Перенос цифры 1. Стало x 3 rev 1.
Шаг 2. Состояние: x 3 rev 1. Перенос цифры 3. Стало x 0 rev 13.
Шаг 3. Проверка 0 равно 13 ложна. Проверка 0 равно 1 ложна.

Итог. Ответ False.
